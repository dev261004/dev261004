- AI-based startup idea validation

- SWOT analysis generation

### 📝 ASSES AI — AI Assignment Evaluation System

ASSES AI is an AI-based assignment evaluation system that evaluates student text-based assignments using a fine-tuned BERT model. It compares student answers with reference answers and generates marks based on semantic understanding.

**Key Features:**

- Assignment evaluation using fine-tuned BERT
- Semantic answer comparison
- Custom dataset of student and reference answers
- Custom fully connected layer on top of BERT
- Text preprocessing pipeline
- Marks generation
- Excel-based output support

**Tech Stack:**  
`Python` `PyTorch` `Hugging Face Transformers` `BERT` `Pandas` `Machine Learning`
